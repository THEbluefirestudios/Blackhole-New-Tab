An aesthetic New Tab extension for Chromium based browsers, featuring a self rendered black hole!

## Features

- A Windows 11 like visuals, complete with my recreation of the mica look (heavy blur + lotta noise).
- Ability to pin an move "apps" (websites) on the Windhawk Luminosity-like taskbar.
- A "start" menu with a short description of the project, link to the [Github Repository](https://github.com/THEbluefirestudios/Blackhole-New-Tab), and settings for visuals and time format.
- Good looking :) [yes i ran out of ideas]

## FAQ

1. **Why isn't this on Chrome Web Store?**
   
    Chrome Web Store requires developers to pay a fee of 5$ to upload extensions to their website, I am a broke teenager, I can't get that money, how less it may be.
   
3. **Why the HELL did you put on Microsoft Edge Addons?**
   
    That's the only Chromium-based Web store that gave free developer accounts, apart from Opera Addons, but that's way less known.

5. **Why are browsers blocking this extension, even when downloaded from the Microsoft Edge addons store?**
   
    This extension changes the default New Tab, and browsers consider this as a threat for some reason idk.
